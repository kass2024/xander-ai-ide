## 📋 **QUICK START GUIDE**

### **1. Start the Application**
```bash
cd apps/web
npm run dev
```

### **2. Register/Login**
- Visit: `http://localhost:3000/auth/register`
- Create account → See success message → Auto-redirect to login
- Login → See success message → Auto-redirect to dashboard

### **3. Explore Dashboard**
- **Main Dashboard**: `http://localhost:3000/dashboard`
- **Settings**: `http://localhost:3000/settings`
- **User Management**: `http://localhost:3000/admin/users`
- **Debug Tools**: `http://localhost:3000/debug`

### **4. Test Features**
- Try registration with duplicate emails
- Test all dashboard sections
- Explore settings and preferences
- Check mobile responsiveness
